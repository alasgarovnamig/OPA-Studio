# Security policy

## Supported versions

Every OPA Studio tag targets one OPA release. Security fixes are applied to `main` and released for the
affected tags through the release workflow; always run the newest build of the tag that matches your OPA
version.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/alasgarovnamig/OPA-Studio/security/advisories/new).
Do not open public issues for security problems. You will get an acknowledgement within a few days.

Vulnerabilities in OPA itself belong to the OPA project: https://github.com/open-policy-agent/opa/security

Hardening guidance: [docs/security.md](docs/security.md).
